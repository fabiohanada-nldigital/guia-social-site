O que é o Guia de Compras Social

É a ferramenta interna que produz e publica os vídeos curtos e carrosséis do Guia de Compras na Web, um site brasileiro de dicas de compra, cupons e ofertas. Ela é usada apenas pela equipe do Guia, para as contas oficiais do próprio Guia. Não é oferecida a terceiros.

Onde publica

InstagramReels e carrosséis pela API oficial da Meta, e resposta no direct a quem comenta a palavra-chave.
FacebookOs mesmos Reels na Página do Guia, pela API oficial da Meta.
TikTokOs mesmos vídeos, enviados pela API do TikTok para a conta do Guia.
YouTubeOs mesmos vídeos, como Shorts, enviados pelos Serviços de API do YouTube para o canal do Guia.

Como funciona

Cada conteúdo parte de um artigo do blog do Guia ou de uma oferta real do site. Um roteiro é escrito, a narração é gerada por inteligência artificial, o vídeo é montado e, depois de aprovado pela equipe, publicado pelas APIs oficiais de cada rede. Quem comenta a palavra-chave recebe no direct o link do grupo de ofertas no WhatsApp.

Dados

A ferramenta só acessa as contas do próprio Guia. Ela não coleta dados de outros usuários do YouTube, do TikTok, do Instagram ou do Facebook além do que as plataformas devolvem sobre as publicações do próprio Guia (contagens de visualizações, comentários e cliques).
