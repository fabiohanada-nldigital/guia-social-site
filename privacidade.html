Política de privacidade

Última atualização: 10 de outubro de 2026.

Esta política descreve como a ferramenta Guia de Compras Social ("a ferramenta"), mantida pela equipe do Guia de Compras na Web ("o Guia"), trata dados ao publicar conteúdo nas redes sociais do Guia.

1. O que a ferramenta faz

A ferramenta publica vídeos e carrosséis produzidos pelo Guia nas contas oficiais do Guia no Instagram, no Facebook, no TikTok e no YouTube, usando as APIs oficiais de cada plataforma, e lê as métricas dessas publicações. Ela é usada apenas pela equipe do Guia e não é oferecida a terceiros.

2. Dados que a ferramenta acessa

  • Contas do próprio Guia: identificadores das contas e páginas do Guia, tokens de acesso concedidos pela equipe do Guia, e os conteúdos publicados pelo Guia.
  • Métricas das publicações do Guia: contagens de visualizações, alcance, curtidas, comentários, compartilhamentos e cliques, fornecidas pelas plataformas.
  • Comentários nas publicações do Guia (Instagram): para responder a quem comenta uma palavra-chave, a ferramenta lê o identificador numérico do comentário e do autor. Ela guarda apenas esses identificadores numéricos e a data; não guarda nome, foto nem texto do comentário.

A ferramenta não coleta dados pessoais de visitantes deste site. Este site não usa cookies de rastreamento.

3. Serviços de API do YouTube

A ferramenta usa os Serviços de API do YouTube (YouTube API Services) para enviar vídeos ao canal do YouTube do próprio Guia e para ler as métricas desses vídeos. Ao usar a ferramenta, a equipe do Guia concorda com os Termos de Serviço do YouTube. O uso dos Serviços de API do YouTube também está sujeito à Política de Privacidade do Google.

A ferramenta acessa, por meio da API do YouTube, apenas os dados do canal do próprio Guia: o envio dos vídeos, seus títulos, descrições e as métricas das publicações. Ela não acessa dados de outros usuários do YouTube e não exibe conteúdo do YouTube a terceiros. Os dados obtidos pela API são guardados apenas nos computadores da equipe do Guia, por até 30 dias para métricas e enquanto o vídeo existir para os identificadores das publicações, e não são compartilhados com ninguém.

A equipe do Guia pode revogar o acesso da ferramenta aos dados do canal a qualquer momento na página de segurança da conta Google: https://security.google.com/settings/security/permissions.

4. APIs do TikTok, do Instagram e do Facebook

Da mesma forma, a ferramenta usa a API do TikTok e as APIs da Meta (Instagram e Facebook) apenas para publicar nas contas do Guia e ler as métricas dessas publicações, dentro dos termos de cada plataforma. A autorização pode ser revogada a qualquer momento nas configurações de cada conta.

5. Com quem os dados são compartilhados

Com ninguém. Os dados ficam nos computadores da equipe do Guia e nos próprios serviços das plataformas. Não há venda, cessão nem uso para publicidade de terceiros.

6. Exclusão de dados

Para pedir a exclusão de qualquer dado guardado pela ferramenta, inclusive dos identificadores de comentários, escreva para guiadecomprasbr@gmail.com. O pedido é atendido em até 15 dias. Os dados obtidos pelas APIs são apagados quando o acesso é revogado.
